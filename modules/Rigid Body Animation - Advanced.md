## 👩‍💻Activity: Rigid Body Animation - Advanced
Animate a scene from Star Wars, such as the Millenial Falcon from [The Last Jedi](https://www.youtube.com/watch?v=ykXWRNZiI3M) or [Empire Stricks Back]https://www.youtube.com/watch?v=GAHW7TF4Tyo
- Dope sheet view in Blender
  - Gives us a similar view to what animators had when they were working in two dimensions
- Actions view within the dope sheet in Blender
  - With actions, we can create discrete animations that can be reused later in the...
- Non-linear editor view in Blender
  - A *non-linear editor* (NLE) is digital video editing software that allows clips to be accessed, edited, and arranged in any sequence along a multitrack timeline without modifying or destroying the original source files (non-destructive editing).
  - In the NLE, we can drop out actions and arrange them across time without going into the details of keyframes, etc.
- Graph editor in Blender
  - A *graph editor* is a visual timeline interface in 3D animation software that displays animation curves, plotting an object's property values (vertical axis) against time (horizontal axis).
  - The graph editor allows us to make very precise changes to how the tweening is done.
